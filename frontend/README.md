# SONAR-AI Frontend Dashboard

Modern Dark Ocean Marine Operations interface built with React, Vite, and Leaflet.

### Quick Start
```bash
# Install dependencies
npm install

# Start development server (http://localhost:5173)
npm run dev

# Production build
npm run build
```

### Environment Configuration
Configure backend API URL by creating a `.env` file:
```env
VITE_API_URL=http://localhost:8000
```
